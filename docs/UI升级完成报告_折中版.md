## 🎨 设计系统总结

### 配色方案

```css
/* 背景 */
--console-canvas: linear-gradient(180deg, #f8fafb 0%, #f0f4f6 100%);
--console-surface: rgba(255, 255, 255, 0.9); /* 半透明 */

/* 品牌色（保持不变）*/
--console-brand: #4fb8a8;
--console-brand-dark: #257e73;
--console-brand-soft: #e8f7f4;
```

### 阴影系统

```css
--console-shadow-sm: 0 2px 8px rgba(30, 50, 55, 0.04);   /* 轻微 */
--console-shadow: 0 4px 12px rgba(30, 50, 55, 0.08);      /* 常规 */
--console-shadow-md: 0 8px 24px rgba(30, 50, 55, 0.12);   /* 中等 */
--console-shadow-lg: 0 12px 32px rgba(30, 50, 55, 0.16);  /* 大 */
--console-shadow-hover: 0 8px 20px rgba(79, 184, 168, 0.15); /* 悬停 */
```

### 圆角系统

```css
--console-radius-xs: 6px;    /* 标签 */
--console-radius-sm: 10px;   /* 按钮 */
--console-radius: 14px;      /* 卡片 */
--console-radius-lg: 18px;   /* 大卡片 */
--console-radius-xl: 24px;   /* 弹窗 */
--console-radius-full: 999px; /* 胶囊 */
```

### 间距系统

```css
--console-space-xs: 4px;
--console-space-sm: 8px;
--console-space-md: 12px;
--console-space-lg: 16px;
--console-space-xl: 24px;
--console-space-2xl: 32px;
--console-space-3xl: 48px;
```

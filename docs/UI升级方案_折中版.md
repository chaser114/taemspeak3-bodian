# UI升级方案 - 折中版（方案A Light）

## 🎯 设计目标

> **"现代但克制，美观但不花哨"**

在保持简洁的基础上，适度增加现代感和层次感。

---

## ✨ 核心改进点

### 保留的元素 ✅

1. **半透明卡片** - 透明度调低到90%，更接近纯白
2. **柔和阴影** - 增强深度感，但不夸张
3. **圆角优化** - 统一且舒适的圆角系统
4. **微妙悬停效果** - 轻微上浮 + 阴影增强
5. **流畅过渡动画** - 300-400ms的自然过渡

### 去掉的元素 ❌

1. ~~动态背景色提取~~ - 保持静态配色
2. ~~夸张动效~~ - 不要爆炸粒子等
3. ~~多彩渐变~~ - 主要用纯色
4. ~~毛玻璃模糊背景~~ - 使用纯色背景

## 🎬 动效方案

### 微交互动效（克制版）

```css
/* 1. 按钮悬停 */
button:hover {
  transform: translateY(-1px); /* 轻微上浮 1px */
  box-shadow: var(--shadow-hover);
  transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

/* 2. 卡片悬停 */
.card:hover {
  transform: translateY(-4px); /* 上浮 4px */
  box-shadow: var(--shadow-lg);
  transition: all 0.3s ease-out;
}

/* 3. 播放按钮点击 */
.play-button:active {
  transform: scale(0.95); /* 轻微缩放 */
  transition: transform 0.1s ease;
}

/* 4. 列表项淡入 */
.list-item {
  animation: fadeInUp 0.4s ease-out;
  animation-fill-mode: both;
}

@keyframes fadeInUp {
  from {
    opacity: 0;
    transform: translateY(10px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* 5. 路由过渡 */
.page-enter-active, .page-leave-active {
  transition: opacity 0.3s, transform 0.3s;
}
.page-enter {
  opacity: 0;
  transform: translateY(10px);
}
.page-leave-to {
  opacity: 0;
}
```

# CeruMusic 风格网页音乐控制台设计规格

日期：`2026-07-16`

## 目标

将现有网页音乐控制台重构为高度借鉴 CeruMusic 桌面播放器的操作框架与视觉语言，同时完整保留现有 TS3 音乐机器人业务能力。

## 参考与授权边界

- 参考仓库：`https://github.com/xie-maker/CeruMusic`。
- 允许借鉴：左侧导航、顶部搜索、底部常驻播放器、队列抽屉、紧凑音乐列表及浅色主题的交互结构。
- 禁止复制：CeruMusic 源码、logo、插画、封面、字体、音频资源及其 AGPL 代码。
- 本项目继续使用现有 Vue 2、Buefy 图标和本项目自身样式实现。

## 页面结构

### 桌面端

1. 左侧固定侧栏：品牌、点歌、最近播放、管理员设置（仅管理员可见）及退出登录。
2. 顶部固定工具栏：返回/前进样式的圆形控件、主搜索框、账号与设置入口。
3. 主内容区：搜索结果与最近播放采用紧凑歌曲行；当前播放状态在内容区展示，但不再占据独立的中间大栏。
4. 底部固定播放器：封面、歌曲信息、上一首/播放暂停/下一首、进度与时间、队列按钮。
5. 队列：右侧滑出抽屉。当前歌曲高亮；仅管理员可见清空队列操作。

### 移动端

1. 不展示桌面侧栏，保留顶部搜索与底部迷你播放器。
2. 底部使用图标导航，管理员设置仅对管理员显示。
3. 点开迷你播放器显示全屏播放视图；队列以底部抽屉展示。
4. 所有触控按钮保留明确图标与可点击尺寸，文本不重叠、不会被播放器遮挡。

### 登录与首次配置

使用与主控制台一致的浅色背景、细边框、圆角输入框和高对比主按钮。首次管理员创建、登录和机器人连接仍沿用现有接口与流程。

## 不变量

- 保留 Cookie 账号登录、首次部署管理员初始化、机器人地址/名称/密码配置和子账号管理。
- 普通网页账号与 TS3 普通用户可以搜索、加入待播、立即播放、上一首和下一首。
- 清空整个待播队列仅管理员可用。
- 保留现有 TS3 聊天命令与权限配置，不改变后端 API 合约。
- 当前歌曲封面继续使用后端提供的 `coverUrl`；缺失时显示本项目内的图标占位。

## 验收标准

1. 在桌面宽度下可见 CeruMusic 式侧栏、顶部搜索栏、底部常驻播放器和可开关的右侧队列抽屉。
2. 在手机宽度下没有水平滚动，底部播放器与导航不会遮挡列表或表单。
3. 普通用户不出现管理入口和清空队列按钮；管理员仍可管理账号、机器人和队列。
4. 搜索、立即播放、加入队列、上一首、暂停/继续、下一首、退出登录和管理员设置继续调用现有 API。
5. 登录、首次配置、音乐页和管理页在视觉上使用同一设计系统。

## 非目标

- 不增加歌词、下载、本地曲库、音量控制或 CeruMusic 的桌面窗口功能。
- 不复制或引入 CeruMusic 的第三方代码、依赖或资源。
- 不改变机器人播放逻辑、酷我插件或 TS3 权限逻辑。
